# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-28

### Added

- Cluster health dashboard — real-time monitoring of physical ClickHouse clusters
- Cluster management and diagnostics — queries, storage, replication, networking, and Keeper
- Database explorer — schema browsing and table lineage visualization
- SQL query editor — query execution, EXPLAIN plans, and query profiling
- ClickHouse user management — users, roles, profiles, and grants
- Rule-based alerting with execution history
- Platform audit logs
- Multi-layer access control and encrypted storage of ClickHouse credentials
- Docker Compose and Kubernetes deployment guides in English and Korean
